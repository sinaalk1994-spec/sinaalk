# STLP Unified

یک پروژه برای وبسایت و ERP، با یک آدرس و یک فرمان اجرا.

اجرا: `python start.py` (Python و Node.js 24 لازم هستند).

سایت: http://127.0.0.1:8770/

ERP: http://127.0.0.1:8770/erp/home.html

مدیریت فروشگاه: از بخش فروشگاه و انبار آنلاین داخل ERP.

داده‌های هر دو نسخه به صورت snapshot کپی شده‌اند؛ فایل‌های قبلی تغییری نکرده‌اند. پس از شروع استفاده از این پروژه، تغییرات نسخه‌های قبلی خودکار به آن منتقل نمی‌شوند.

موتور ERP با Node و موتور فروشگاه با Python در همین پروژه اجرا می‌شوند؛ درگاه مشترک هر دو را روی یک پورت نمایش می‌دهد. ورودها و دیتابیس‌ها فعلاً مجزا هستند. ثبت فاکتور فروشگاه در حسابداری و انتقال کالا هنوز پیاده‌سازی نشده است.

این اجرا مخصوص کامپیوتر محلی است؛ برای انتشار اینترنتی نیاز به تفکیک دسترسی ERP، HTTPS و تنظیم میزبانی دارد.
